WHAT THIS LAB ESTABLISHES

      
Every green result has a boundary.

      

        RaceLab executes the submitted JavaScript handler in isolated
        QuickJS/WebAssembly. It controls the order of asynchronous operations
        against a simulated store. It does not run arbitrary Node.js
        repositories, real database transactions, HTTP timing or
        operating-system threads.
      

      

        The examples are authored fixtures. The recorded repairs come from
        actual Meta API investigations. A finite sweep reports only the input
        cases and schedules it checked; it does not prove universal correctness
        or production safety.
      

      

        Sequential, round-robin and seeded random baselines can also expose
        these simple races. The scheduler's work is explicit. Meta supplies
        experiment proposals and candidate source; code supplies the verdict.
      

      

        Related work includes
        REINS
        and
        deterministic simulation testing. RaceLab claims a focused implementation, not invention of these
        methods.
      

      

        Built by Tang Vu during the hackathon. Meta provides Muse Spark and
        Llama. QuickJS and quickjs-emscripten provide the JavaScript runtime.
        This standalone repository reuses Meta transport and accounting code
        from Tang Vu's earlier hackathon prototype, LiveWorld.
